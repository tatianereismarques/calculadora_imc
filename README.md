# Funcionalidades:
* Interface intuitiva: substituindo os inputs via terminal por campos de texto. 
* Validação de dados: Tratamento de erros para entradas vazias ou dados inválidos.
* Classificação automática: o sistema calcula o IMC e categoriza o resultado. 
* Botão de ação: O cáluclo só é iniciado após o preenchimento dos campos "Peso" e "Altura" e acionamento do botão "Calcular".

# Como executar o objeto localmente: siga os passos abaixo em seu terminal.
1. Instalação do Streamlit: pip install streamlit
2. Iniciar a aplicação: python -m streamlit run calculadora_imc.py
3. O navegador abrirá automaticamente a interface pronta para uso.
